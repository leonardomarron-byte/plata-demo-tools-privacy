Plata Demo Tools

Política de Privacidad

Última actualización: 16 de septiembre de 2026

1. Descripción

Plata Demo Tools es una herramienta de apoyo que proporciona una demo interactiva en formato flotante y una calculadora complementaria de rendimientos dentro del navegador.

2. Recopilación de datos

Plata Demo Tools no recopila, almacena en servidores, vende ni transmite información personal del usuario.

La extensión no recopila nombres, direcciones, correos electrónicos, contraseñas, información financiera, información de autenticación, ubicación, historial de navegación ni contenido de las páginas web visitadas.

3. Almacenamiento local

La extensión utiliza el almacenamiento local de Chrome únicamente para conservar preferencias de funcionamiento de la interfaz, tales como posición, tamaño y estado de la ventana flotante.

Esta información permanece localmente en el navegador del usuario y no se envía a servidores externos.

4. Permisos de Chrome

activeTab: se utiliza únicamente cuando el usuario activa la extensión para permitir mostrar temporalmente la interfaz flotante en la pestaña actual.

scripting: se utiliza para insertar y mostrar la interfaz de Plata Demo Tools en la pestaña activa cuando el usuario solicita abrirla.

storage: se utiliza para guardar localmente preferencias de interfaz como posición, tamaño y estado del flotante.

Estos permisos no se utilizan para recopilar ni transmitir información del contenido de las páginas.

5. Compartición de datos

Plata Demo Tools no vende, comparte ni transfiere datos de los usuarios a terceros.

6. Código remoto

Plata Demo Tools no ejecuta código JavaScript o WebAssembly descargado desde servidores externos. El código necesario para el funcionamiento de la extensión se encuentra incluido dentro del paquete de la extensión.

7. Seguridad

La extensión está diseñada para funcionar localmente dentro del navegador y limitar sus permisos a las funciones necesarias para mostrar la demo y sus herramientas complementarias.

8. Cambios en esta política

Esta Política de Privacidad puede actualizarse si las funciones o permisos de Plata Demo Tools cambian. La versión publicada en esta página será la vigente.

9. Contacto

Para preguntas relacionadas con esta Política de Privacidad, el usuario puede contactar al desarrollador mediante la información de contacto proporcionada en la ficha de Chrome Web Store.
